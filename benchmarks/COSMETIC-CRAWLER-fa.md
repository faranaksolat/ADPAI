# کراولر عکس محصولات آرایشی‌بهداشتی کره‌ای

این ابزار برای گردآوری **عکس واقعیِ نامزدهای بازبینی** نوشته شده است. هدف پیش‌فرض ۵۰ محصول متمایز است، تا سه عکس برای هر محصول. رسیدن به هدف یعنی دانلود فایل‌های قابل‌رمزگشایی، نه تأیید عکس مواد، کره‌ای‌بودن محصول، کامل‌بودن پنل یا آمادگی برای آموزش/ارزیابی. اسکنر و مدل‌های اپ در این تغییر دست‌کاری نشده‌اند.

## اجرا در ویندوز

Python نسخهٔ ۳٫۱۰ یا جدیدتر لازم است. فایل‌های `crawl-cosmetics.py` و `crawl-cosmetics-windows.cmd` را در یک پوشه قرار دهید و فایل CMD را اجرا کنید. در زیرپوشهٔ `data` یک محیط مجازی محلی ایجاد و Pillow نسخهٔ ثابت ۱۲٫۳٫۰ در آن نصب می‌شود. سپس تلاش برای گردآوری حداکثر ۵۰ محصول آغاز می‌شود؛ کلید API یا حساب کاربری نمی‌خواهد. نصب خودکار Python انجام نمی‌شود.

اجرای دستی در PowerShell:

```powershell
py -3 -m venv .cosmetics-venv
.\.cosmetics-venv\Scripts\python.exe -m pip install Pillow==12.3.0
.\.cosmetics-venv\Scripts\python.exe crawl-cosmetics.py --output .\cosmetics-50 --limit 50 --ingredient-hints-only
```

پوشهٔ خروجی باید جدید باشد؛ ابزار هیچ نتیجه یا رونویسی قبلی را بازنویسی نمی‌کند. برای تلاش بعدی نام تازه‌ای انتخاب کنید. ازسرگیری خودکارِ دانلود قبلی هنوز پیاده‌سازی نشده است. فایل CMD برای هر اجرا نام تازه می‌سازد.

در محیط پروژه:

```sh
.venv/bin/python benchmarks/crawl-cosmetics.py --output benchmarks/data/cosmetics-50-NEW --limit 50 --ingredient-hints-only
```

## منابع و دامنهٔ واقعی کار

- Open Beauty Facts: API عمومی ProductOpener؛ عکس اصلیِ برگزیده‌شدهٔ پنل مواد به کره‌ای/انگلیسی، با شناسهٔ عکس و نام بارگذار. متن مواد API فقط `reference_hint_UNVERIFIED` است. جست‌وجوی فعلی محصولاتِ ثبت‌شده در بازار کره را می‌بیند و اتصال کره‌ای را از فهرست محدود نام برندها یا فرادادهٔ محل ساخت غربال می‌کند؛ همهٔ محصولات کره‌ای جهان را پوشش نمی‌دهد. بارکد ۸۸۰ یا کشور فروش به‌تنهایی ملاک نیست.
- فهرست عمومی برندهای COSRX، Beauty of Joseon و Round Lab: قالب عمومی Shopify `products.json`، فقط با نام vendor متناظر. وجود این endpoint و ساختار زندهٔ هر سایت باید در اجرا تأیید شود؛ سازگاری آن‌ها در محیط مسدود فعلی روی وب زنده تأیید نشده است.
- لینک مستقیم محصول در سایت‌های دیگر: فقط HTML عمومی با `Product` در JSON-LD، نام برند مطابق فهرست و عکس‌های اعلام‌شدهٔ محصول؛ صفحه‌های نیازمند اجرای JavaScript، ورود، CAPTCHA یا پیمایش فروشگاه‌های دیگر پشتیبانی نمی‌شوند. JavaScript صفحات اجرا نمی‌شود.

فقط یک منبع:

```sh
python crawl-cosmetics.py --source cosrx --output cosrx-NEW --limit 50 --ingredient-hints-only
```

افزودن صفحهٔ محصول دیگر، به جای جست‌وجوی خودکار چهار منبع، با URL واقعی:

```sh
python crawl-cosmetics.py --url https://STORE_HOST/PRODUCT_PATH --image-host IMAGE_CDN_HOST --output extra-NEW --limit 50 --ingredient-hints-only
```

عبارت‌های `STORE_HOST`، `PRODUCT_PATH` و `IMAGE_CDN_HOST` جای‌نگهدارند و باید جایگزین شوند. اگر نام برند در فهرست اولیه نیست، `--korean-brand "BRAND NAME"` فقط یک سرنخِ اعلام‌شده از طرف اجراکننده اضافه می‌کند؛ تأیید منشأ نیست. چند `--url`، `--source` یا `--image-host` مجاز است.

`--ingredient-hints-only` عکس فاقد سرنخ مواد را کنار می‌گذارد. انتخاب پنل توسط ارائه‌دهنده یا وجود `ingredients` / `전성분` در alt/نام فایل **تشخیص بصری پنل نیست** و به‌عنوان تأییدشده شمرده نمی‌شود. بدون این گزینه، عکس محصول با پنل نامعلوم نیز ذخیره می‌شود؛ ممکن است عکس جلوی بسته یا تصویر تبلیغاتی باشد. شمارهٔ محصولات واجد سرنخ جدا از تعداد محصول و تعداد عکس گزارش می‌شود.

## خروجی و محدودیت‌ها

- `images/`: بایت‌های اصلی JPEG/PNG/WebP، بدون بازفشرده‌سازی یا دست‌کاری.
- `index.html`: گالری محلیِ عکس‌های واقعی دانلودشده با پیوند منابع؛ مقادیر نام و توضیح escape می‌شوند. این فایل کد سایت مبدأ را اجرا نمی‌کند.
- `products-UNREVIEWED.jsonl`: محصول، برند، URL، سرنخ پنل/زبان، ابعاد، SHA-256 فایل و پیکسل‌ها، زمان دریافت و وضعیت حقوق.
- `review-UNREVIEWED.jsonl`: فرم مستقل بازبینی؛ متن خالی، پنل کامل نامشخص، خانواده و تقسیم داده نامشخص، بدون ادعای تأیید انسان.
- `snapshots/` و `requests.jsonl`: پاسخ‌های فهرست/صفحه، robots و رخدادهای درخواست برای بازتولید و بررسی منشأ.
- `collection-report.json`: شمار محصولات و عکس‌های دانلودشده، شمار سرنخ‌ها، کسری نسبت به هدف، خطاها و منابع متوقف‌شده. `benchmark_ready` و شمار پنل‌های تأییدشده در این مرحله همیشه false/صفرند.

تکرار شناسهٔ منبع، نام نرمال‌شدهٔ برند+محصول، هش بایت یا پیکسل یکسان حذف می‌شود. عکسِ تغییراندازه‌داده‌شده، فرمول اصلاح‌شده، اندازه‌های مختلف یا اسم‌های متفاوت ممکن است هنوز به یک خانواده تعلق داشته باشند؛ گروه‌بندی خانواده/شباهت نزدیک نیازمند بازبینی است. سه عکس یک محصول، سه محصول شمرده نمی‌شوند.

robots.txt بررسی می‌شود؛ ۴۰۱/۴۰۳/۴۲۹ و خطاهای شبکه توقف همان میزبان را ایجاد می‌کنند. robots ناموجود با ۴۰۴/۴۱۰ طبق RFC 9309 متفاوت از رد دسترسی است. تغییر پروکسی، دورزدن CAPTCHA، تکرار خودکار یا دنبال‌کردن redirect انجام نمی‌شود. در redirect باید نشانی canonical را جداگانه بررسی و صریحاً انتخاب کرد. فقط HTTPS و میزبان‌های دقیق مجازند؛ ابزار تنظیمات شبکهٔ محیط ابری را تغییر نمی‌دهد. TLS بررسی می‌شود و متغیرهای پراکسی/اعتماد CA محیط حفظ می‌شوند.

پیش‌فرض: مکث حداقل یک ثانیه و برای API جست‌وجوی Open Beauty Facts هفت ثانیه، حداکثر پنج صفحه برای هر فهرست، ۳۰۰ درخواست با احتساب robots؛ سقف هر پاسخ فراداده ۴ مگابایت، عکس ۲۴ مگابایت و ۴۰ میلیون پیکسل. crawl-delay / request-rate طولانی‌تر نیز رعایت می‌شود؛ تأخیر بالای ۶۰ ثانیه به زمان‌بندی دستی نیاز دارد. تصاویر بندانگشتی زیر ۲۰۰ پیکسل در هر ضلع کنار گذاشته می‌شوند.

کد خروج ۰ یعنی رسیدن به هدفِ **نامزدهای بازبینی**؛ ۲ یعنی مجموعه ناقص/دسترسی مسدود. کمبود هرگز با محصول جعلی یا مرجع ساخته‌شده پر نمی‌شود. توقف با Ctrl+C شواهد قبلی را حفظ می‌کند. اجرای CMD در ویندوز در این محیط لینوکسی تست نشده است؛ هستهٔ Python با آزمون‌های آفلاین بررسی می‌شود.

مجوز عکسِ فروشگاه از عمومی‌بودن صفحه نتیجه نمی‌شود. حقوق بازنشر همهٔ نمونه‌ها بازبینی‌نشده باقی می‌ماند. عکس/متن خام خودکار در GitHub یا اپ منتشر نمی‌شود؛ پوشهٔ `benchmarks/data/` در `.gitignore` است. قبل از آموزش یا سنجش دقت، حقوق استفاده، خود تصویر پنل، نام محصول، نسخهٔ فرمول و منشأ کره‌ای باید بررسی شوند؛ سپس رونویسی مستقل دو نفره، رفع اختلاف و جداسازی خانواده‌های توسعه/آزمون لازم است.

## آزمون ابزار

```sh
.venv/bin/python -m unittest discover -s tests -p 'test_cosmetic_crawler.py' -v
```

تمام تصاویر این تست‌ها ساختگی و برای اعتبارسنجی انتقال/فایل/فراداده‌اند؛ گذشتن تست‌ها به معنی دانلود ۵۰ محصول واقعی یا دقت بالینی نیست. این ابزار هیچ OCR، LLM، آموزش مدل یا نتیجهٔ «ایمن» تولید نمی‌کند.
