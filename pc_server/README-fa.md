# سرور آزمایشی ADPAI روی ویندوز

این نسخه عکس را از مرورگر گوشی به رایانهٔ خودت می‌فرستد و با PaddleOCR محلی
می‌خواند؛ هزینهٔ API هوش مصنوعی ندارد. صفحهٔ آزمایشی انگلیسی/کره‌ای، انتخاب
آلرژن، خواندن برچسب و منو، متن اصلی و هشدار عدم قطعیت را دارد. اپ نصب‌شده و
سایت گیت‌هاب خودکار به آن متصل نمی‌شوند. مدل LLM یا آموزش مدل اضافه نشده است.

برای دسترسی بیرون خانه از تونل موقت HTTPS شرکت Cloudflare استفاده می‌کند؛
عکس‌ها از زیرساخت آن شرکت عبور می‌کنند. این اتصال مستقیمِ سرتاسری بین دو
دستگاه نیست. هیچ API ابریِ هوش مصنوعی عکس را پردازش نمی‌کند. منبع دانلود مدل
Paddle فایل مدل را دریافت/ارسال می‌کند، نه عکس شما را.

## راه‌اندازی

۱. فایل ZIP سرور را در یک پوشه از حالت فشرده خارج کن. ویندوز ۶۴ بیتی، Python
۳٫۱۱ و اینترنت برای نصب اولیه لازم است. در PowerShell می‌توانی نصب کنی:

```powershell
winget install --id Python.Python.3.11 -e
winget install --id Cloudflare.cloudflared -e
```

این‌ها نصب‌کننده‌های رسمی‌اند. پنجرهٔ فرمان را بعد از نصب ببند و دوباره باز کن.
تنظیمات Play Protect، TLS، مودم یا فایروال را خاموش نکن.

۲. روی `Start-PC-Server.cmd` دوبار بزن. برنامه محیط Python مخصوص همین پروژه را
می‌سازد و وابستگی‌ها را نصب می‌کند؛ نصب اولیه و اولین دریافت مدل ممکن است طول
بکشد. رایانه به GPU نیاز ندارد، ولی سرعت CPU و حافظه تعیین‌کننده است؛ سرعت روی
ویندوز و گوشی تو هنوز اندازه‌گیری نشده است.

۳. لینک کامل جلوی `PRIVATE PHONE LINK` را فقط برای خودت به گوشی بفرست و در
مرورگر باز کن. انتهای `#token=...` را حذف نکن. این لینک کلید دسترسی خصوصی است؛
آن را در گیت‌هاب یا شبکه‌های اجتماعی منتشر نکن. متن انتخاب آلرژی در مرورگر
می‌ماند؛ فقط عکس‌ها برای OCR به رایانه می‌روند.

۴. رایانه و همین پنجره باید روشن بمانند؛ با `Ctrl+C` متوقف می‌شود. لینک موقت
ممکن است با هر اجرای دوباره تغییر کند و کد قبلی با راه‌اندازی مجدد باطل می‌شود.
در حالت Sleep، خاموشی یا قطع اینترنت سرویس در دسترس نیست.

خواندن عکس در پس‌زمینه انجام می‌شود و گوشی وضعیت را با درخواست‌های کوتاه
پیگیری می‌کند. متنِ نتیجه، پس از اتمام، حداکثر پنج دقیقه در حافظهٔ رایانه می‌ماند
و حداکثر دو نتیجه نگهداری می‌شود؛ عکس در آرشیو نتیجه ذخیره نمی‌شود.

## محدودیت‌ها

این تونل برای آزمایش شخصی است و تضمین پایداری سرویس حرفه‌ای ندارد. دامنهٔ ثابت،
میزبانی دائمی، کاربران متعدد و انتشار اپ، مرحله‌های جدا هستند. هیچ خرید، مصرف
اعتبار یک‌میلیون وونی، بازکردن پورت مودم یا انتشار فروشگاهی انجام نمی‌شود.

امتیاز Paddle مربوط به کل خط است؛ آن را به امتیاز معتبر تک‌تک کلمات تبدیل
نکرده‌ایم. متن‌های مشکوک می‌توانند به‌عنوان «خطر احتمالی» نشان داده شوند، اما
هیچ غذا یا محصولی ایمن اعلام نمی‌شود. نام غذا جای دستور یا فهرست کامل مواد را
نمی‌گیرد. خطای شبکه یا قطع سرور نتیجهٔ ایمن تولید نمی‌کند.

عکس موقت بعد از اتمام واقعی پردازش از رایانه حذف می‌شود؛ قطع مرورگر لزوماً کار
در حال اجرا را متوقف نمی‌کند. حذف عادی فایل، پاک‌سازی امن دیسک نیست و خرابی
سیستم ممکن است فایل موقت باقی بگذارد. درخواست بعدی هنگام مشغول‌بودن رایانه
پذیرفته نمی‌شود تا چند پردازش سنگین هم‌زمان شروع نشود.

ساختار و آزمون‌های Linux/مرورگر در گزارش همراه بسته ثبت می‌شوند؛ آماده‌بودن
این کد به معنی آزمایش واقعی ویندوز، اتصال بیرون خانه یا دقت کافی نیست. یک تصویر
نمونهٔ بدون اطلاعات شخصی را ابتدا آزمایش کن و نتیجه را با نوشتهٔ اصلی تطبیق بده.

برای اجرای فقط روی خود رایانه و بدون تونل:

```powershell
py -3.11 -m pc_server.launch --install
```

## اعتبار طرح

اعتبار «모두의 창업» لزوماً پول نقد برای هر API دلخواه نیست. قبل از انتخاب
بسته باید واجدشرایط‌بودن، پشتیبانی ارسال تصویر، مدل‌های مجاز، سقف هزینه، مدت و
انقضای اعتبار، نگهداری عکس و هزینهٔ بعد از پایان حمایت مشخص شود. این سرور
به حساب طرح دسترسی ندارد و هیچ هزینه‌ای از آن برداشت نمی‌کند.
