# اعتبار یک‌میلیون وونی و API

API راه ارتباط برنامه با سرور است. این سرور می‌تواند روی رایانهٔ شما مدل
محلی را اجرا کند؛ یا در مرحله‌ای دیگر به یک مدل ابری پولی درخواست بدهد. میزبانی
روی رایانه، هزینهٔ مدل ابری را در صورت استفاده از آن حذف نمی‌کند.

نسخهٔ فعلی فقط PaddleOCR محلی را اجرا می‌کند. هیچ حساب طرح، اعتبار، سرویس
پولی LLM یا خریدی به آن متصل نشده است. هزینهٔ API مصرف‌شده در این کار صفر است.
دانلود اولیهٔ مدل، برق، اینترنت و روشن‌ماندن رایانه همچنان لازم‌اند.

برای خرج‌کردن اعتبار «모두의 창업» باید ابتدا این موارد دربارهٔ بستهٔ مورد
تأیید طرح روشن شود:

- آیا اعتبار برای API قابل استفاده است یا فقط اشتراک همان ابزار؟
- آیا API تصویر و مدل مناسب خواندن انگلیسی/کره‌ای را پشتیبانی می‌کند؟
- قیمت ماهانه است یا اعتبار مصرفی؟ مالیات، انقضا و هزینهٔ بعد از حمایت چیست؟
- عکس‌ها کجا پردازش/نگهداری می‌شوند و آیا برای آموزش ارائه‌دهنده مصرف می‌شوند؟
- آیا سقف هزینه و توقف خودکار قابل تنظیم است و مصرف واقعی هر آزمایش گزارش می‌شود؟

در تصویر ارسالی شما قیمت BizRouter ماهانه ۱٬۰۰۰٬۰۰۰ وون و Onpod ماهانه
۵۰۰٬۰۰۰ وون نوشته شده بود؛ این، تأیید امکانات یا شرایط قرارداد فعلی نیست.
بستهٔ یک‌میلیون وونیِ ماهانه می‌تواند کل سقف حمایتی شما را مصرف کند. قبل از
پیش‌فاکتور و روشن‌شدن شرایط، خرید یا تمدید خودکار انجام نمی‌دهیم.

انتخاب مدل باید با مقایسه روی منوهای بازبینی‌شده صورت بگیرد: خطای خواندن،
مواد جاافتاده، اتصال ماده به غذای درست، حدس‌های بی‌پشتوانه، زمان و هزینهٔ هر
تصویر. مدل LLM هنوز در این نسخه اضافه نشده و هیچ مدل تازه‌ای آموزش ندیده است.
