Private PC test · Privacy

This companion uploads chosen photographs to your own running PC. It is separate from the public on-device website and installed APK. If the remote Cloudflare tunnel is used, requests and photographs pass through Cloudflare infrastructure under its terms. This is not an end-to-end encrypted direct device connection. No cloud AI API or paid inference is used.

Photos use temporary files on the PC, removed after the actual decode/OCR job finishes, including failures. Disconnecting the browser may not stop a job already running. Deletion is not secure disk erasure; operating-system errors or crashes may leave temporary files. At most two completed OCR text results remain in PC memory, each expiring five minutes after completion. No gallery, photo/result disk archive, account or training upload is created. Model files may be downloaded from Paddle's official servers, without photographs. No advertising or analytics scripts are added. The selected allergy profile stays in the browser.

The private pairing code is held in this browser tab's session storage. A link fragment is removed from the address bar after pairing; it is not sent as a URL query. Keep the private link/code secret. Restarting the launcher generates a new code. The companion does not register an offline cache. Tunnel/hosting providers and operating systems have their own logging rules.

개인정보 처리 요약

선택한 사진은 실행 중인 내 PC로 업로드됩니다. 외부 접속 터널 사용 시 Cloudflare를 거치며 기기 간 종단간 암호화 연결은 아닙니다. 클라우드 AI API는 사용하지 않습니다. 선택한 알레르기 성분은 브라우저에 남습니다. 임시 사진은 실제 판독 작업이 끝나면 삭제하지만 운영체제 오류 시 남을 수 있습니다. 완료된 원문 결과는 최대 2개, 각 완료 후 5분 동안 PC 메모리에 보관합니다. 연결 코드는 탭의 세션 저장소에 보관합니다. 비공개 링크를 공개하지 마세요. 결과는 안전을 보장하지 않습니다.
