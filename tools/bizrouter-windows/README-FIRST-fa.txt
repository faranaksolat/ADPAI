اتصال کدنویسی ADPAI به اعتبار BizRouter — ویندوز

این بسته، همین گفت‌وگوی ChatGPT را به BizRouter منتقل نمی‌کند. یک جلسهٔ مستقل Codex CLI روی رایانهٔ شما راه می‌اندازد. درخواست‌های مدل در آن جلسه از مسیر BizRouter ارسال و طبق تعرفهٔ مدل از اعتبار آن حساب محاسبه می‌شوند. انتقال خودکار تاریخچهٔ چت انجام نمی‌شود؛ فایل خلاصهٔ پروژه همراه بسته است.

۱. ZIP را کامل Extract کنید؛ فایل‌های CMD را داخل ZIP اجرا نکنید.
۲. Node.js نسخهٔ LTS، نسخهٔ ۲۲ یا جدیدتر، باید نصب باشد: https://nodejs.org/en/download
۳. CONNECT-WINDOWS.cmd را اجرا کنید. ابزارها در زیرپوشهٔ ADPAI-BizRouter در LocalAppData نصب می‌شوند؛ به نصب سراسری قبلی شما دست نمی‌زند.
۴. دستور login مرورگر را باز می‌کند. با حسابی که اعتبار دریافت کرده وارد شوید؛ کد همان اجرای ترمینال و مرورگر را مقایسه و سپس تأیید کنید. کد نمایشیِ نمونه در سایت را وارد نکنید. کلید و توکن واقعی را در چت نفرستید.
۵. Git for Windows باید نصب باشد: https://git-scm.com/downloads/win
۶. START-CODING-WINDOWS.cmd را اجرا کنید. اگر پوشهٔ ADPAI کنار بسته وجود نداشته باشد، مخزن main را در آن دریافت می‌کند؛ پوشهٔ موجود بدون Git را بازنویسی نمی‌کند.
۷. در جلسهٔ Codex بنویسید: «ابتدا فایل ADPAI-HANDOFF-2026-11-01.md را بخوان و سپس ادامهٔ کار ADPAI را به فارسی انجام بده.» بعد کار مشخص موردنظر را بنویسید.

برای استفاده از مخزن موجود در PowerShell:
.\START-CODING-WINDOWS.cmd "C:\PATH\TO\ADPAI"

کلید API در ذخیره‌سازی محلی خود ابزار BizRouter قرار می‌گیرد. فایل credentials.json، کلید، توکن و لینک‌های خصوصی را منتشر نکنید. واردشدن روی ویندوز، به این گفت‌وگوی ابری دسترسی به آن کلید یا کنترل رایانهٔ شما نمی‌دهد.

مدیریت کنسول BizRouter از طریق MCP در این راه‌انداز خاموش است؛ جلسه برای کدنویسی و فراخوانی مدل است. تنظیم دائمی Codex و حالت‌های تأیید فرمان/امنیت آن تغییر داده نمی‌شوند. برای بررسی تعرفه، مدل و سقف مصرف از کنسول BizRouter استفاده کنید؛ موجودی تخصیص‌یافته سقف مصرف روزانه نیست. انتخاب پیش‌فرض مدل و مصرف آن را با سقف دلخواه خود در کنسول بررسی کنید.

این راه‌انداز نه سایت را خودکار منتشر می‌کند، نه API داخل اپ ADPAI را متصل کرده است. برای API داخل اپ همچنان سرور امن، کلید سمت سرور، مدل سازگار با تصویر و رضایت ارسال عکس لازم است.

اعتبارسنجی این بسته: راهنمای رسمی npm و سورس bizrouter@0.3.12 با SHA-512 رجیستری تطبیق داده شد؛ parser گزینه‌ها و تنظیم provider برای Codex با کلید ساختگی، بدون ورود، شبکه یا inference بررسی شدند. فایل‌های CMD روی ویندوز در این محیط اجرا نشده‌اند؛ ورود حساب، انتخاب مدل، مانده‌حساب و مصرف واقعی تأیید نشده‌اند.
