# دامنه و میزبانی ADPAI

دامنه، آدرس برند است؛ میزبانی، جایی است که فایل‌ها یا برنامه اجرا می‌شوند.
خرید دامنه به‌تنهایی سرور پردازش عکس ایجاد نمی‌کند. دامنه را می‌توان از شرکتی
جدا از میزبان خرید. ثبت و تمدید دامنه معمولاً هزینهٔ جداگانه دارد؛ قیمت و آزاد
بودن نامی مانند `adpai.app`، `adpai.kr` یا `adpai.com` هنوز بررسی یا تأیید نشده است.
هیچ نام یا سرویس پولی در این مرحله خریداری نشده است.

## مسیر پیشنهادی

| مرحله | صفحه و ظاهر اپ | پردازش تصویر |
| --- | --- | --- |
| نمونهٔ فعلی | GitHub Pages و بعداً دامنهٔ اختصاصی | همان پردازش داخل گوشی/مرورگر |
| آزمایش شخصی سرور | صفحهٔ همراه سرور، با لینک خصوصی موقت | رایانهٔ روشن ویندوزی و تونل HTTPS |
| بتای عمومی | میزبانی ثابت وب با شرایط مناسب استفادهٔ تجاری | سرور ثابت یا سرویس API با سقف هزینه و سیاست عکس روشن |

برای دموی فعلی، خرید هاست جدا ضروری نیست. GitHub Pages از دامنهٔ اختصاصی و
HTTPS پشتیبانی می‌کند. پس از انتخاب و ثبت دامنه، DNS و بخش Custom domain باید
با هم تنظیم شوند؛ HTTPS نیز پس از آماده‌شدن گواهی فعال می‌شود. مسیرهای نسبی
برنامه برای دامنهٔ اختصاصی حفظ شده‌اند. تنظیم DNS یا اتصال دامنه هنوز انجام نشده است.

برای عرضهٔ تجاری، میزبان باید استفادهٔ تجاری موردنظر را مجاز بداند. GitHub Pages
برای اجرای اصلی کسب‌وکار آنلاین یا SaaS محدودیت استفاده دارد؛ پیش از تبدیل دمو
به سرویس تجاری، شرایط آن یا گزینه‌هایی مانند Cloudflare Pages و میزبانی وب
متناسب بررسی شوند. هزینهٔ API هوش مصنوعی نیز مستقل از دامنه و میزبانی است.

## رایانهٔ شخصی به عنوان میزبان

رایانه می‌تواند سرور باشد. در نسخهٔ آزمایشی، برنامه به آدرس داخلی رایانه متصل
است و Cloudflare یک لینک خصوصی موقت HTTPS به آن می‌دهد. عکس از زیرساخت
Cloudflare عبور می‌کند؛ متن انتخاب آلرژی در مرورگر می‌ماند. این حالت به بازکردن
پورت مودم یا خاموش‌کردن فایروال نیاز ندارد.

رایانه باید روشن، بیدار و متصل بماند؛ خاموشی، Sleep یا قطع اینترنت، سرویس را
متوقف می‌کند. لینک موقت ممکن است با اجرای دوباره تغییر کند و دامنهٔ دلخواه به
صورت خودکار به این تونل وصل نمی‌شود. دامنهٔ ثابت روی تونل به تنظیمات جداگانهٔ
حساب و DNS نیاز دارد. برای چند کاربر و سرویس دائمی، سرور ثابت مدیریت‌شده
انتخاب مناسب‌تری است؛ پشتیبان‌گیری، به‌روزرسانی، نظارت و ظرفیت پردازش هم باید
در نظر گرفته شوند. سرور فعلی برای یک کار سنگین هم‌زمان ساخته شده است.

ظاهر جدید، دقت OCR را تغییر نمی‌دهد. برچسب و منوی نامطمئن همچنان ایمن اعلام
نمی‌شوند. نسخهٔ نصب‌شدهٔ APK با تغییر سایت خودکار به‌روزرسانی نمی‌شود؛ فایل
نسخهٔ تازه باید نصب شود. سرور خصوصی هم خودکار روی رایانهٔ کاربر راه نمی‌افتد.
